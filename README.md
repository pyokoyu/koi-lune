# Koi Lune 〜星降る恋の占い館〜

[▶ 無料で遊ぶ](https://koi-lune.github.io/) · [テスト結果](./TEST_REPORT.md)

2026年11月27日以降の投稿・案内には https://koi-lune.github.io/ を使用します。11月26日までの公開済み投稿・記事は変更しません。

旧サイト https://pyokoyu.github.io/koi-lune/ とこのリポジトリは維持します。強制転送は行わず、旧URLの保存データはそのまま利用できます。新URLへの保存データの自動移行はありません。

青髪の占い師と白猫が案内する、5種類の無料恋愛ゲーム。添付試作版を基にしたブラウザゲームです。

- 恋愛タロット：大アルカナ22種の専用イラスト・正位置／逆位置・1枚／3枚引き・図鑑
- 星の相性：ニックネームから作る娯楽スコア。入力の送信・保存なし
- 白猫の恋みくじ：日本時間で日替わり
- 心理テスト：8問・4タイプ。心理検査ではなく、気持ちを振り返る遊び
- 恋物語：全6章・4結末、途中保存、章を戻る操作
- 結果30件の履歴、PNG保存、コピー、X投稿画面へのリンク、note・X（@koi_lune7）・Instagram（@koi_lune）への導線
- スマホ向け配置、キーボード操作、動きを減らす設定への対応、任意の効果音

占い・診断は娯楽です。未来や相手の気持ちを確定するものではありません。

## 動かす

ビルド不要。`python3 -m http.server 4173` を実行し、`http://localhost:4173` を開きます。ES modulesを使用するので、HTMLのファイル直開きではなくHTTPで配信してください。

本番実行に外部API・広告・解析・CDN・課金サービスは使いません。ブラウザ内のlocalStorageにのみ保存します。X・noteは明示的にリンクを押した場合のみ開きます。

## テスト

Node.js 22以上。

```sh
npm install
npm test
npx playwright install --with-deps chromium webkit
npm run test:browser
```

純粋な計算・保存処理と画像の文字組みの14テストに加え、ChromiumとWebKitで画面操作・保存・PNG・再開・6画面幅・エラー時動作を検証します。心理テスト256通り、物語64通りはロジックテストで全探索します。実際のiPhone/Android端末での動作を保証するものではありません。

## 公開

現行サイトは公開リポジトリ `koi-lune/koi-lune.github.io` のGitHub Pagesを使用します。このリポジトリ `pyokoyu/koi-lune` は旧サイトの公開を維持します。Settings → Pages → SourceをGitHub Actionsに設定。mainへのpush後、公開用のHTML・JS・CSSにコミット単位のバージョンを付け、その配信ファイルをブラウザでテストしてから公開します。古いプログラムがブラウザに残ることによる更新漏れを防ぎます。公開リポジトリの標準ランナーとPagesの無料枠を使い、有料オプションは使用しません。

釣りゲーム・note自動生成システムには依存せず、それらのファイル／設定を変更しません。

## 素材

元のキャラクターとメイン画像はユーザー提供。22種のカード絵は、提供画像を参照してChatGPT内の画像生成機能で制作したアトラスです。独立した有料APIは使用していません。アトラスは6列×4行で、先頭22セルをカードに使用します。残り2セルは装飾用です。コードのカード枠と日本語名は別レイヤーです。
